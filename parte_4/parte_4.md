1. Explica la diferencia entre Git y GitHub.
R: GIT: motor de control de versiones.
   GITHUB: plataforma de colaboración en la nube.

2. Explica para qué sirve .gitignore.

R: Para evitar subir el entorno virtual o cosas inncesarias al repositorio.

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.

R: Por su peso, es dependiente del sistema y no es portable.


4. Explica para qué sirve requirements.txt.
R: Permite almacenar las librerias instalas para que otro usuario las instale y pueda correr sin problema el programa.

5. Explica la diferencia entre Stage, Commit y Push.
R: Stage(git add): prepara los archivos para ser incluidos en el próximo commit.

Commit: guarda los cambios que estaban en stage dentro del repositorio local.

Push: Envia los commits al repositorio local.

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.

Para realizar un historial de commits o historial de cambios.
